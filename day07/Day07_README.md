# Day 7: For Loops and Lists

## What I Learned

- What a `for` loop is and how it repeats code for each item in a collection.
- How to use `range()` with `for` loops.
- How to loop through a string one character at a time.
- What lists are and how they store multiple values.
- How list indexes work and why indexing starts at `0`.
- How to access individual items in a list.
- How to add new items to a list using `.append()`.
- How to combine `for` loops, lists, and `if` statements.
- How loops can be used to examine multiple security-related records.

## Security Practice

I created a Python program that stores multiple user accounts in a list and scans each account using a `for` loop.

The program checks each account and identifies privileged accounts based on predefined security conditions.

I also practiced adding a new account to the list and keeping track of the number of privileged accounts detected.

### **Assignment for Day 7**

**Security Account Scanner**

The program:

- Stores multiple account names in a list.
- Adds an additional account using `.append()`.
- Uses a `for` loop to scan every account.
- Uses conditional logic to identify privileged accounts.
- Counts the number of privileged accounts.
- Displays the security status of each account.
- Displays the total number of privileged accounts.

This assignment helped me understand how Python can scan multiple records automatically and identify accounts that require additional security attention.
