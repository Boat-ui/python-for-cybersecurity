# Python for Cybersecurity

A 90-day journey of learning Python with a focus on cybersecurity.

## About Me

I'm a BSc Information Technology graduate from the University of Energy and Natural Resources (UENR), Ghana, building my skills in cybersecurity and Python.

## Why I'm Learning Python

I'm learning Python to build a strong programming foundation and apply it to practical cybersecurity tasks.

My goal is to become comfortable using Python for:

- Cybersecurity automation
- Log analysis
- Network security
- Security scripting
- Data processing
- Threat detection
- Security tools and utilities

## My 90-Day Goal

By the end of this journey, I want to be able to use Python confidently to build practical cybersecurity scripts and understand how Python can be applied to real-world security problems.

This repository documents my progress, exercises, assignments, and projects throughout the 90 days.
