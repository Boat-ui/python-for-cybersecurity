# Day 8: Functions and Return Values

## What I Learned

- What functions are and why they are useful.
- How to define a function using `def`.
- How to call a function.
- How to pass information into a function using parameters and arguments.
- How to use multiple parameters in a function.
- How `return` sends a result back from a function.
- The difference between `print()` and `return`.
- How to store a returned value in a variable.
- How returned values can be used in later security decisions.
- How functions make security logic reusable.

## Security Practice

I created a security login analysis function that accepts a username and number of login attempts.

The function evaluates the number of attempts and returns a risk level based on the activity.

I then used the returned result to display the appropriate security classification.

### **Assignment for Day 8**

**Login Risk Analyzer**

The program:

- Creates a function that accepts a username and login attempts.
- Uses conditional logic to evaluate the attempts.
- Returns an appropriate risk level.
- Stores and uses the returned result.
- Displays the user's security risk level.

This assignment helped me understand how functions can organize and reuse security analysis logic.
