# Day 5: Security Decision Logic

## What I Learned

- How to combine conditional statements to make security-related decisions.
- How nested `if` statements can be used to check conditions in stages.
- How `and` can require multiple conditions to be true.
- How `or` can allow a decision when at least one condition is true.
- How `elif` can provide additional decision paths.
- How conditional logic can be used to classify activity based on security indicators.
- How to build simple security checks using information provided by a user.

## Security Practice

I created a small security check program that combines multiple conditions to make a security decision.

The program uses information such as a user's age and failed login attempts to demonstrate how Python can evaluate several conditions and respond differently depending on the situation.

This helped me understand how conditional logic can be applied to simple cybersecurity scenarios.

### **Assignment for Day 5**

**Security Check Program**

The program:

- Collects relevant information from the user.
- Uses multiple conditions to evaluate the information.
- Combines conditional statements to make a security decision.
- Uses `if`, `elif`, and `else` where appropriate.
- Produces different results depending on the conditions.

This assignment helped me practice combining the conditional concepts learned so far to build a more realistic security-related Python program.
