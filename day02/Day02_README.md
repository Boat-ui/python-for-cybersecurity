# Day 2: Variables, Input and Type Conversion

## What I Learned

- What variables are and how they store information in Python.
- How to create variables and assign values to them.
- How to work with integers in Python.
- How to collect information from a user using `input()`.
- How `input()` returns user input as a string.
- How to convert input into an integer using `int()`.
- How to convert values into strings using `str()`.
- How Python can perform arithmetic operations with numerical values.
- How variables and user input can be combined to make programs interactive.

## Security Practice

I created simple Python programs that collect information from the user and use variables to store and process that information.

I practiced converting user input into numbers and using those values in calculations.

These concepts form an important foundation for building interactive cybersecurity scripts that collect and process information.

### **Assignment for Day 2**

**Security Information Program**

The program:

- Uses variables to store information.
- Collects information using `input()`.
- Converts numerical input into an integer.
- Performs an operation using the collected values.
- Displays the result using `print()`.

This assignment helped me understand how Python programs can collect, store, convert, and process information provided by a user.
