# Day 4: Logical Operators and Nested Conditions

## What I Learned

- How to combine multiple conditions in Python.
- How the `and` operator works.
- How the `or` operator works.
- How `and` requires both conditions to be true.
- How `or` requires at least one condition to be true.
- How to use `elif` to check additional conditions.
- How to use nested `if` statements.
- How nested conditions allow a program to make decisions inside another decision.
- How multiple conditions can be used to create more detailed security decisions.

## Security Practice

I created Python programs that use multiple conditions to make security-related decisions.

I practiced combining conditions with `and` and `or`, using `elif` for additional outcomes, and placing an `if` statement inside another `if` statement.

These concepts helped me understand how security programs can evaluate multiple pieces of information before making a decision.

### **Assignment for Day 4**

**Security Login Checker**

The program:

- Collects relevant login information from the user.
- Uses multiple conditions to evaluate the information.
- Uses `and` and `or` where appropriate.
- Uses `if`, `elif`, and `else`.
- Uses a nested condition.
- Displays an appropriate security-related result.

This assignment helped me understand how multiple conditions can be combined to create more detailed security decision-making logic.
