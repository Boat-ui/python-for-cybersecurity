# Day 3: Conditions and Boolean Logic

## What I Learned

- How comparison operators work in Python.
- How to compare values using operators such as `>`, `<`, `>=`, `<=`, `==`, and `!=`.
- What Boolean values are: `True` and `False`.
- How `if` statements allow a program to make decisions.
- How `else` provides an alternative when an `if` condition is false.
- How indentation determines which statements belong to a condition.
- How conditions can be used to make simple security decisions.

## Security Practice

I created Python programs that compare values and make decisions based on the results.

I practiced using Boolean expressions with `if` and `else` statements to determine whether a condition was true or false.

These concepts introduced me to decision-making in Python, which is important for creating security programs that can respond differently depending on what is detected.

### **Assignment for Day 3**

**Security Access Checker**

The program:

- Collects information from the user.
- Uses a comparison to evaluate the information.
- Uses an `if` statement to make a decision.
- Uses `else` for the alternative outcome.

This assignment helped me understand how Python can evaluate conditions and make decisions based on the information it receives.
