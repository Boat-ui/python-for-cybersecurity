# Day 9: Dictionaries

## What I Learned

- What dictionaries are and how they store information using key-value pairs.
- How to create a dictionary.
- How to access values using dictionary keys.
- How to update existing dictionary values.
- How to add new key-value pairs.
- How to loop through dictionary keys and values.
- How to use `.get()` to safely access dictionary values.
- How to provide a default value when a key does not exist.
- How dictionaries can represent structured security information.

## Security Practice

I created a security login record using a dictionary containing information such as a username and login attempts.

I practiced reading, updating, and adding information to the record and using `.get()` when a key might not exist.

### **Assignment for Day 9**

**Security Login Record Analyzer**

The program:

- Stores security information in a dictionary.
- Reads values using dictionary keys.
- Updates existing information.
- Adds new security information.
- Uses `.get()` to safely retrieve information.
- Displays the information stored in the security record.

This assignment helped me understand how dictionaries can be used to organize structured security data.
